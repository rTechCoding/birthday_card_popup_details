# 🎉 Happy Birthday Memories

A sweet and interactive birthday memories webpage where each image opens a special birthday message. Designed to create an emotional, joyful experience through visuals and simple interactions.

---

## ✨ Features

- 🎂 Birthday-themed UI with soft pastel colors  
- 🖼️ Clickable image cards that reveal hidden birthday messages  
- 💖 Memory-driven layout for a personal touch  
- 📱 Fully responsive design (desktop & mobile friendly)  
- 🎈 Simple, clean, and lightweight frontend implementation  

---

## 🛠️ Built With

- HTML5  
- CSS3  
- JavaScript (for interactions & message reveal)

---

## 📸 Preview

The page displays a warm **“Happy Birthday Memories”** heading followed by image cards.  
Clicking on any image opens a special birthday message, making each moment memorable.
